# Eye Trends Vision & Glasses Center's real site is https://www.eyetrendsclearlake.com/
# See docs/PROVENANCE.md before changing this file.

# CRAWLING is allowed so this build can be audited with site crawlers
# (Screaming Frog, Sitebulb, etc.).
#
# SEARCH INDEXING is blocked at the page level instead: every page carries
#   <meta name="robots" content="noindex, follow">
# That is a STRONGER control than a robots.txt Disallow, because a Disallow
# only stops crawling -- it does not remove URLs already known to a search
# engine, and it actually prevents crawlers from ever SEEING a noindex tag.
# Allowing the crawl is what lets the noindex be read and obeyed.
#
# Do not remove the per-page noindex tags. This copy must not compete with
# the practice's real site in search results.
